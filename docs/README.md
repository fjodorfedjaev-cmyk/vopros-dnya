# Подробности по частям сайта

Общий короткий контекст — в файле, который прикладывается к чату. Здесь — подробности. **Читать только файл той части, с которой работаем.**

| Файл | Что внутри |
|---|---|
| `question.md` | Вопрос, Слово, Выбор, Гороскоп, «Свой вопрос», «Выбор от друзей», правила для вопросов |
| `coins.md` | Монеты (откуда берутся, `coins_of`, экономика), своя монета, Казино |
| `sector.md` | Сектор (все правила) и Дуэли |
| `cards.md` | Коллекционные карточки, витрина, Лавка (рынок с заявками) |
| `durak.md` | Китайский дурак |
| `poker.md` | Покер |
| `bluff.md` | Верю — не верю |
| `site.md` | Зигзаг, Ферма, Профиль, мини-профиль, окошки «нажатием мимо», уведомления, значки, установка |

Скрипты локальной проверки и команды запуска — `tools/local-test/README.md`.

Правила для этих файлов:
- После изменения части — обновить её файл здесь (что есть сейчас, а не историю «раньше было так»).
- Что и как проверили — писать в сообщении коммита, а не в файлах.
- Имён друзей и личных данных здесь не писать: репозиторий открытый.
