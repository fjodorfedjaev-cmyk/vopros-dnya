# Вопрос дня — контекст проекта

## 1. Что за сайт
- Сайт для меня и друзей, учебный проект. Вход по коду приглашения.
- **Вопрос дня:** ответы друзей видны только после своего ответа. Есть реакции эмодзи и комментарии (к своему ответу — только ответы на чужие комментарии).
- **Слово дня:** вписать слово в пропуск фразы.
- **Гороскоп** по знаку зодиака.
- **Сектор:** мини-игра на реакцию, рейтинг за неделю и за всё время.
- **Казино:** Дабл, Сапёр, Краш на монеты.

## 2. Стек и хостинг
- Код: GitHub `fjodorfedjaev-cmyk/vopros-dnya`, ветка main.
- Сайт: GitHub Pages — https://fjodorfedjaev-cmyk.github.io/vopros-dnya/
- Фронтенд: чистый HTML/CSS/JS (`app.js`, `game.js`, `casino.js`), PWA (`manifest`, `sw.js`).
- База: Supabase (Postgres, RLS, функции; Auth по почте и паролю).
- Уведомления: Edge Function `push`, расписание через pg_cron, ключи в Vault.

## 3. Сделано и работает
- Все вкладки: Вопрос/Слово (переключатель), Гороскоп, Игра, Казино, Профиль.
- Серии дней, статистика, архивы, обновление в реальном времени.
- Монеты (до сотых), считает база:
  - +20 за вопрос, +20 за слово;
  - бонус за серию 3/7/30/100 дней;
  - 1 монета за 10 очков в игре, без ограничений.
- Казино: прибыль ≈6,7% (1/15); исход решает только база; Сапёр — от 2 мин.
- Уведомления: напоминание раз в 3 дня (если нет ответа) и о комментарии к своему ответу.
- Установка как приложение: иконка «Солнце дня», подсказка об установке.

## 4. Планы

- Отложено: друзья (скрывать ответы от части людей) — я ещё продумываю.
- Возможно: отдельный тип для подарков монет (сейчас записываются как «игра» с пометкой gift).

## 5. Решения, которые нельзя забыть
- Дизайн тёмный: фон #121212, карточки #1E1E1E, оранжевый #F2782C, кнопки #C4500B. В казино оранжевый вместо красного.
- Вопросы: смешные и «норм или стрём», не личные, не про компанию (в приложении люди из разных компаний), без мужского или женского рода.
- Ярлыков вида вопроса нет. Монеты — валюта, а не рейтинг. Звуков и вибрации нет.
- Не публиковать код приглашения и секретные ключи. Удалять данные из базы — только с моего подтверждения.

## 6. Баги и открытые вопросы
- Chrome показывает своё уведомление «Tap to copy the URL», если приложение стоит ярлыком. С сайта это не убрать.
- На iPhone ставить только через Safari, не изнутри Telegram.
- Старые версии функций базы переименованы в `*_old` и закрыты — удаление требует подтверждения.
